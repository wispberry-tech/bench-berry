# BerryBench — Agent Guidelines

## Rules

- Every plan starts with a bullet-point TLDR.
- Keep all documentation language concise and straightforward.
- Dev mode: drop DB tables and rerun migrations and seed data freely.
- Never force push (`--force` / `--force-with-lease`) — pushed history is shared; fix commits with a new commit on top.
- Ask before committing (`git add`, `git commit`).
- Never use archived or dead docs!
